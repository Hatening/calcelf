# CalcElf UI System v4.2

## Credits visual system

The numeric Credits value remains explicit. The illustration adds context and emotional feedback.

### Four tiers
- Tier 4 — Plenty: 500+ for larger paid balances.
- Tier 3 — Healthy: 100–499.
- Tier 2 — Running low: 20–99.
- Tier 1 — Critical: <20.

For Free/small-base accounts the frontend uses a ratio baseline so a newly granted small balance is not treated as critical only because its absolute number is small.

### Child mode — Magic Tree
Tier 4 is a lush green tree with sun and flowers. Tier 3 relaxes the leaves. Tier 2 adds yellow/olive leaves, stronger droop and a visible watering can. Tier 1 becomes sparse and the watering can has a stronger bounce/water-drop animation. The copy asks the child to water the tree; the button still opens the normal Credits purchase flow.

### Adult/parent mode — Credit Vault
Tier 4 shows a full gold vault and coin stacks. Tier 3 reduces visible stacks. Tier 2 becomes sparse and introduces a replenishment cue. Tier 1 leaves an almost-empty vault with a card/chip and warning spark.

### Membership
The sidebar now has a Membership Journey card exposing the monthly and lifetime tracks already present in the product model. The lifetime level is represented by a growth icon and progress; the monthly level is shown separately.

### Design rule
Layout stays stable. Lifetime membership can control the main palette; monthly state can add accents and effects. This follows the product planning rule of keeping functionality stable while changing color/light/decor.
