## 二、系统架构（5 个逻辑层）

```
┌─────────────────────────────────────────────┐
│  编排层 (orchestrator)                        │
│  路由 / 级联 / 排队 / 缓存 / 质量门            │
│  知识卡 → free HTML → 静态步骤卡               │
├─────────────────────────────────────────────┤
│  知识卡层 (kards)                             │
│  分类 → 抽参 → 解题 → 校验 → 渲染参数          │
│  每族一个 JS 模块，确定性代码                   │
├─────────────────────────────────────────────┤
│  引擎层 (renderer/core)                       │
│  画布 / DPR / 动画循环 / 时间轴 / 缓动          │
├─────────────────────────────────────────────┤
│  模式层 (renderer/modes)                      │
│  每族一个 render(canvas, anim)                │
├─────────────────────────────────────────────┤
│  原子层 (renderer/atoms)                      │
│  演员 / 形状 / 标注 / UI 组件                  │
└─────────────────────────────────────────────┘
```

## 三、渲染技术决策

- **Canvas 三层**：core（引擎）→ modes（各族渲染）→ atoms（原子零件）
- **为什么 3 层**：保障动画质量（core 统一计时/缓动/DPR）+ UI 质量（atoms 统一设计令牌）+ 可扩展性（modes 各族独立）
- **free HTML 保留**：作为长尾受控兜底，降低 reasoning_effort、主/兜底分别留时间（25s+25s）、超时不盲目重试
- **静态步骤卡**：最后兜底，绝不白屏

## 四、环境变量（Vercel 配置）

| 变量名 | 默认值 | 说明 |
|---|---|---|
| SOLVE_MODEL | deepseek-flash | 解题主模型（flash，便宜快） |
| SOLVE_STRONG_MODEL | deepseek-v4-pro | 解题强模型兜底 |
| ANIMATION_FREE_MODEL | deepseek-flash | free HTML 主模型 |
| ANIMATION_FREE_FALLBACK_MODEL | deepseek-v4-pro | free HTML 兜底 |
| ANIMATION_FREE_REASONING_EFFORT | high | free HTML 推理强度 |
| KARD_TIMEOUT_MS | 8000 | 知识卡超时（毫秒） |
| FREE_HTML_TIMEOUT_MS | 25000 | free HTML 超时 |
| DEEPSEEK_API_KEY | （必填） | DeepSeek API Key |
| SUPABASE_URL | （必填） | Supabase 项目 URL |
| SUPABASE_SERVICE_KEY | （必填） | Supabase 服务端密钥 |
| CREEM_API_KEY | （必填） | Creem 收款密钥 |

> 模型名不带任何前缀。DeepSeek 为 OpenAI 兼容：BASE_URL https://api.deepseek.com

## 五、部署步骤

1. **解压 zip**：解压交付的 `calcelf-phase1.zip`
2. **全选文件与文件夹**：不要只选外层文件夹
3. **拖到 GitHub 仓库根目录**：覆盖已有文件
4. **提交并推送**：`git add . && git commit -m "Phase 1: knowledge cards + 8 families" && git push`
5. **Vercel 自动部署**：无构建步骤，直接生效
6. **配置环境变量**：在 Vercel Project Settings → Environment Variables 中配置上表
7. **验证**：访问 calcelf.vercel.app，测试解题→动画→聊天全流程

## 七、质量门

- 黄金集通过率 ≥ 90%
- 每族必含至少 1 个图形场景（纯 say/show 判不合格）
- 可见文字必须为目标语言（11 种：en, zh-CN, zh-TW, ja, ko, fr, de, es, it, ar, fa）
- 抽参置信度 < 0.3 不硬画
- 知识卡 p95 延迟目标 < 8–12s
- 兜底仅按信号触发（超时/报错/无图形）

## 八、铁律

- 前端根目录与 public/ 镜像逐字节一致（cp 后 cmp）
- lib/*.js 只放 /lib，public/lib 不得存在
- 真正执行的端点在 root/api，以 vercel.json 为准
- animation/animation-plan/solve maxDuration = 60
- 绝不把源码/思考显示到页面
- 绝不硬套、绝不白屏
