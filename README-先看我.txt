CalcElf v5.1 素材与文档补充包
================================
部署不需要本包！部署只用 calcelf-deploy-v5.1.zip（4.97MB 精简包）。
本包是完整存档的剩余部分：
- brand/：吉祥物未抠底原稿（mascot-*.png、pose-*.png）和暂未启用的姿势抠底图
- docs/ 与 *.md：产品规则、部署说明、变更记录等文档

如何拼成完整工程存档（可选）：
1. 解压 calcelf-deploy-v5.1.zip，得到 calcelf-deploy-v5.1 文件夹
2. 把本包 brand/ 里的图片复制进 calcelf-deploy-v5.1/brand/（同名选跳过）
3. 把 docs/ 文件夹和 *.md 文件复制进 calcelf-deploy-v5.1/ 根目录
说明：原完整包里有一个误打包的嵌套重复文件夹 brand/brand/（3.2MB 重复图片），
已剔除，不影响任何功能。
