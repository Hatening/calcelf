v6.1 数据流（双渲染层）：
  用户解题 → /api/solve → 插入 asked_questions → 返回 qid + result
       ↓
  animation() → POST /api/kard（10s）
    ├─ renderer 族命中（axis_motion/motion/...）→ host="renderer"
    │   → iframe /renderer/index.html → postMessage {animation:renderParams} → Canvas 动画
    ├─ board 族命中（函数/圆锥/立体/化学/...）→ host="2d"|"3d"|"reaction"|"solid"
    │   → iframe /board/{host}.html → postMessage {board,lesson,steps} → 交互式板
    │   → board-router: 关键词分类 → LLM 生成 board JSON → validateBoard 校验 → 重试
    └─ 均不命中 → /api/animation(free) → /api/animation-plan(plan) → static
  所有成功路径 → 5星评分 → /api/rate-animation → /api/log-animation
       ↓
  每周一 14:30 UTC → /api/cron-distill → 聚合 → distill_batches

============================================================
族 → host 映射：
  axis_motion / motion / numberline / bars / grid / balance / geometry → renderer（v6.0）
  board_function_graph / board_conics / board_analytic_geometry /
  board_vector / board_physics_motion / board_statistics / board_logic → 2d
  board_physics_3d → 3d
  board_solid_geometry → solid
  board_chemistry → reaction
